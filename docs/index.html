wgsql — GPU GROUP BY in your browser

A WGSL kernel runs SELECT key, SUM(value) GROUP BY key on your GPU. Compares against a JavaScript Map baseline on the same data. Source: github.com/shiahonb777/wgsql.

checking WebGPU support…

GPU wins big at high cardinality (≥100 K groups) and large data (≥10 M rows). At low cardinality (1 K groups), JS Map fits in CPU L2 cache and beats the GPU's atomic-contention bottleneck. Try both regimes.
